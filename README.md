# 🌍 MonGuess

Геоугадайка для игры с друзьями. Показывает снимок улицы, вы ставите точку на карте —
чем ближе, тем больше очков (до 5000 за раунд).

**Главное отличие от GeoGuessr — все страны.** Каждый раунд — новая страна, страны
выбираются равновероятно из набора выбранной сложности (на сложной — из всех ~225). Снимки берутся из двух источников:

- **Google Street View** — официальные панорамы Google плюс уличные фотосферы, которые
  выкладывают люди (их много даже там, где машины Google не ездили). Сначала ищется
  съёмка самого Google, фотосферы — только если её рядом нет;
- **Mapillary** — фото с улиц от пользователей, есть почти во всех странах.

Если в выбранной стране ничего не нашлось, игра берёт следующую страну.

## Ключи

Нужен хотя бы один, вписываются в `config.js`.

**Mapillary (бесплатно):**
1. Войти на https://www.mapillary.com (можно через аккаунт Facebook).
2. Открыть https://www.mapillary.com/dashboard/developers → Register application.
3. Название любое, права — только Read.
4. Скопировать **Client Token** (`MLY|…`) в `mapillaryToken`.

**Google (необязательно, бесплатно до ~1000 игр в месяц):**
1. https://console.cloud.google.com → создать проект, привязать карту (Billing).
2. Включить **Maps JavaScript API**.
3. Credentials → Create API key → вписать в `googleApiKey`.
4. Обязательно ограничить ключ: Application restrictions → Websites → адрес вашего сайта.
   Ещё можно поставить квоту в день, чтобы точно не заплатить.

Бесплатно 5 000 загрузок панорам в месяц; игра из 5 раундов — 5 загрузок.
Поиск мест при сборке игры (`getPanorama`) не платный и в лимит не входит: платна только
показанная панорама (`StreetViewPanorama`).

## Запуск

На своём Mac, с ключами из Связки ключей (элементы `monguess-mapillary` и `monguess-google`):

```bash
scripts/play.sh
```

Скрипт поднимает сервер на http://localhost:8765 и открывает игру в браузере;
`config.js` при этом собирается из Связки ключей на лету, ключи не попадают в файлы.
Остановить — Ctrl+C. Порт фиксированный: ключ Google ограничен адресом `http://localhost:8765/*`.

Без Связки ключей: вписать ключи в `config.js` и запустить `python3 -m http.server 8000`.
Открывать `index.html` двойным кликом нельзя — браузер не даст загрузить `data/places.json`.

В меню есть настройка **«Фотосферы людей»**: без них (только машины Google), только те,
по которым можно ходить (у точки есть соседние), или любые, даже одиночные.

Настройка **«Сложность»** решает, из каких стран выбираются места, по тому, насколько страна
известна обычному игроку: лёгкая — 54 самые известные страны, средняя (по умолчанию) — плюс ещё
70, сложная — все страны. Список уровней — `COUNTRY_TIERS` в `lib.js`. Панорама, которая у
границы оказалась в стране не своего уровня, пропускается. В комнате действует сложность того,
кто её создал; она видна в лобби и записывается в лог (`settings.difficulty`).

## Проверка

```bash
scripts/verify.sh
```

Синтаксис всех файлов и тесты `lib.js` и функции лога (`node --test`). Ноль на выходе — всё зелёное.

## Выкладка

Сайт живёт на Cloudflare Pages: https://monguess.pages.dev. Выложить текущую версию:

```bash
scripts/deploy.sh
```

Скрипт сначала выкладывает Worker комнат `monguess-rooms` (папка `rooms/`), потом сайт.
Ключи берутся из Связки ключей (плюс `monguess-cloudflare` — токен с правами
«Cloudflare Pages: Edit», «Workers KV Storage: Edit» и «Workers Scripts: Edit», и
`monguess-cloudflare-account` — ID аккаунта) и попадают только в выкладываемую копию `config.js`. У ключа Google в ограничениях должен быть адрес
`https://monguess.pages.dev/*`. Скрипт выкладывает только чистый `master`, совпадающий с GitHub.

## Лог игр

Каждая игра оставляет одну запись на сервере: функция `functions/api/log.js` в том же проекте
Cloudflare Pages кладёт её в Workers KV (пространство `monguess-log`, его id — в `wrangler.toml`).
В записи: места раундов (источник, id панорамы, страна, координаты, съёмка Google, фотосфера
или Mapillary), ответы и очки, сколько собиралась игра, ошибки (панорама не загрузилась, места
не нашлись). Игра в комнате пишется так же, у каждого игрока своя запись, с полем `room` (id
комнаты). Личных данных нет — только имя игрока из меню. Запись уходит в начале игры,
в конце и при закрытии страницы посреди игры; если отправка не удалась, игра этого не замечает.

Прочитать последние игры:

```bash
scripts/logs.sh        # последние 10
scripts/logs.sh 30     # последние 30
scripts/logs.sh --raw  # записи как есть, JSON
```

Токен и аккаунт — те же `monguess-cloudflare` и `monguess-cloudflare-account` из Связки ключей;
токену нужны оба права: «Cloudflare Pages: Edit» (выкладка) и «Workers KV Storage: Edit» (лог).

Аккаунт Cloudflare на бесплатном плане: 1 000 записей в KV в день (игра — две-три записи).
Сверх лимита лог молча перестаёт писаться до следующего дня, игра работает как обычно;
денег бесплатный план не списывает.

## Игра с друзьями

После игры нажмите **«Ссылка для друзей»** — по ней друзья сыграют те же места и
смогут сравнить счёт. Чтобы ссылка работала у друзей, сайт нужно выложить в интернет,
например на Netlify или Cloudflare Pages (бесплатно, просто загрузить папку).

**Вживую, в комнате:** кнопка **«Играть с друзьями»** под «Играть» находит места так же,
как обычная игра (те же настройки раундов и снимков), создаёт комнату и открывает её
лобби со ссылкой `#r=<id>`. Кто открыл ссылку, вписывает имя и входит; список игроков
обновляется сам, «Начать» может нажать любой. В настройках — **«Режим игры с друзьями»**:
без времени (раунд ждёт всех) или таймер после первого ответа (15, 30, 60 или 120 секунд).
Все видят одну и ту же панораму и ставят точку, как в обычной игре. После ответа карта
запирается, вверху видно, сколько игроков уже ответило («Ответили 2 из 3»), а в режиме
таймера после первого ответа у всех идёт обратный отсчёт; кто не успел, получает 0. Итоги
раунда показывают ответы всех на одной карте с именами и таблицу (ошибка, очки за раунд,
сумма), а через 5 секунд следующий раунд начинается сам. После последнего раунда кнопка
«Итоги» открывает общую таблицу по раундам.

Комнатам нужен Worker `monguess-rooms`, поэтому `scripts/play.sh` их не поднимает.
Локально — два процесса (порт сайта 8765 из-за ключа Google; `<site>` — копия сайта с
`config.js`, собранным из Связки ключей, как это делает `scripts/deploy.sh`):

```bash
(cd rooms && npx --yes wrangler@4.151.3 dev --port 8801)
(cd <site> && npx --yes wrangler@4.151.3 pages dev . --port 8765 --do ROOMS=Room@monguess-rooms)
```

## Как устроено

- `index.html`, `style.css`, `lib.js`, `app.js` — вся игра, без сборки. В `lib.js` чистые функции
  (очки, расстояния, ссылка для друзей, запись лога, ссылка на комнату и первое сообщение
  комнате), их проверяют тесты в `tests/`. Сокет комнаты — один блок в `app.js`.
- `functions/api/log.js` — приём лога игр на Cloudflare Pages, `wrangler.toml` — его привязки.
- `rooms/` — отдельный Worker `monguess-rooms` с Durable Object `Room`: одна живая комната на
  объект. Сайт ходит в него через `functions/api/room/[id].js` (WebSocket `/api/room/<id>`).
  Правила комнаты и протокол сообщений — в `rooms/rules.js` (чистые функции, тесты в
  `tests/rooms.test.js`). Проверка на выложенном сайте — партия двух игроков:
  `node scripts/room-smoke.js https://monguess.pages.dev`.
- `data/places.json` — ~7300 городов по странам из [Natural Earth](https://www.naturalearthdata.com)
  (общественное достояние). Случайная точка берётся в 1–40 км от случайного города страны.
- Страна снимка определяется через Nominatim (OpenStreetMap).
- Карта — Leaflet + OpenStreetMap.
